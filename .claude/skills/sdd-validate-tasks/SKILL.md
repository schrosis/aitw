# sdd-validate-tasks

タスクの文書を検証します。結果は報告するだけで、文書もコードも変えません。

## 手順

1. [約束事](../../sdd/conventions.md) と [置き場](../../sdd/storage.md) を読む
2. 置き場から要件、設計、タスクの文書を読む。どれかがなければ止めて、書くスキルを案内する
3. [タスクの分け方](../sdd-tasks/rules/tasks.md) の「書く前の関門」と「形の決まり」をすべて確かめる。
   特に次のことを確かめる
   - すべての受け入れ基準の番号が、どれかのサブタスクにある
   - 同じ Wave の PR の境界が、設計の「ファイルの構成」で同じファイルを触らない
   - `_Depends:_` に書かれていないのに、前の PR の成果を使う PR がない
   - 大タスクとサブタスクの行のほかに、行の先頭が `- [ ] ` の行がない
4. 下の形で報告する

## 報告

- **判定:** 直すべき問題があれば `issues`、なければ `ok`
- **問題:** 問題ごとに、場所（Wave と大タスクの番号）、内容、直し方の案。`ok` なら「なし」
