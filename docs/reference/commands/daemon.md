# ugoke daemon

```text
ugoke daemon start [options]
ugoke daemon stop
ugoke daemon status
```

常駐プロセスを起動、停止し、その状態を表示します。常駐プロセスは、ホストに 1 つだけ動き、Temporal Server を起動して、登録したプロジェクトのステップを実行します。仕組みは「[アーキテクチャ](../../explanation/architecture.md)」で説明します。

## ugoke daemon start

常駐プロセスをバックグラウンドで起動します。

| オプション              | 内容                                                                                               |
| ----------------------- | -------------------------------------------------------------------------------------------------- |
| `--address <address>`   | 開発サーバーを起動せずに、このアドレスの Temporal Server を使います                               |
| `--dev-db <path>`       | 開発サーバーの記録の SQLite のファイルです。今のディレクトリからのパスです。既定は、状態のディレクトリの `temporal.db` です        |
| `--temporal-bin <path>` | 開発サーバーを起動する Temporal CLI です。パスか、`PATH` にあるコマンドの名前です                 |
| `--dev-ui`              | Web UI も起動します                                                                                |
| `-h`, `--help`          | ヘルプを表示します                                                                                 |

`--address` は、`--dev-db`、`--temporal-bin`、`--dev-ui` と一緒に使えません。

- `--address` を指定しなければ、開発サーバーを起動します。開発サーバーは実行の記録を残します
- 常駐プロセスのファイル（ソケット、ログなど）は、状態のディレクトリの `daemon/` に置きます。状態のディレクトリは `$XDG_STATE_HOME/ugoke` で、`XDG_STATE_HOME` がなければ `~/.local/state/ugoke` です
- すでに動いていれば、新しく起動せずに終わります。動いている常駐プロセスと ugoke のバージョンやサーバーのオプションが違うときは、そのことを表示します。変えるときは、`ugoke daemon stop` で止めてから起動し直します
- script ステップは、常駐プロセスを起動したときの環境変数を引き継ぎます

## ugoke daemon stop

常駐プロセスを止めます。常駐プロセスは、実行中のスクリプトが終わるのを待ってから止まります。

## ugoke daemon status

常駐プロセスのプロセス ID、サーバー、ugoke のバージョン、起動した時刻、ログのファイル、登録したプロジェクトを表示します。

## プロジェクトの登録

常駐プロセスのサーバーを使う `ugoke run`、`ugoke attach`、`ugoke cancel` は、そのプロジェクトを常駐プロセスに登録します。常駐プロセスは、プロジェクトごとに Worker を動かし、ステップを実行します。登録したプロジェクトは、常駐プロセスを起動し直しても覚えています。`.ugoke` がなくなったプロジェクトは、起動し直したときに外します。Worker を起動できなかったプロジェクトも登録は残し、次に登録するときに起動し直します。

常駐プロセスと ugoke のバージョンが違うときは、そのことを表示して、コマンドが自分でステップを実行します。

## 終了ステータス

| コマンド | 値  | 意味                                                                                     |
| -------- | --- | ---------------------------------------------------------------------------------------- |
| `start`  | `0` | 起動した。すでに動いていた                                                               |
| `start`  | `1` | 起動に失敗した。60 秒たっても答えなかった                                                |
| `stop`   | `0` | 止めた。動いていなかった                                                                 |
| `stop`   | `1` | 60 秒たっても止まらなかった                                                              |
| `status` | `0` | 動いている                                                                               |
| `status` | `1` | 動いていない                                                                             |
