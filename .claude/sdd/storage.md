# 文書の置き場

SDD のスキルが読み書きする文書の置き場です。置き場を変えるときは、このファイルを書き換えます。

## 今の置き場

リポジトリの作業ツリーにある Markdown ファイルに置きます。`<name>` は作業の名前です。

| 文書   | 場所                               |
| ------ | ---------------------------------- |
| 要件   | `docs/work/<name>/requirements.md` |
| 設計   | `docs/work/<name>/design.md`       |
| タスク | `docs/work/<name>/tasks.md`        |

## 読み書きのしかた

- 読むときは Read を使う
- 初めて書くときは Write を使う。Write は、文書がまだないときだけ使う
- 直すときは Edit で、直すところだけを直す
- `docs/work/` は Git で追跡していない。上書きすると戻せないため、ある文書を Write で書き直さない

## 置き場を変えるとき

Confluence や Jira などに移すときは、この節のほかに次のものも合わせて直します。どれも、今の置き場がファイルであることを前提にしています。

- このファイルの「今の置き場」と「読み書きのしかた」
- `.ugoke/workflows/plan.yaml`: 文書を表示するスクリプトと、AI ステップの `allowedTools`
- `.ugoke/workflows/develop.yaml`: PR を拾うスクリプト、完了の印を付けるスクリプト、文書を読む AI ステップの指示
